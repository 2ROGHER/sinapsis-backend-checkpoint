Sinapsis — Campañas de Marketing SMS API (1.0.0)

Download OpenAPI specification:

Roger Mestanza: rogers.mestanza@gmail.com License: MIT

API para la prueba técnica de Backend Semi-Senior de Sinapsis. Expone un endpoint de reporte de mensajes activos programados por estado de envío (filtrable por mes obligatorio y cliente opcional) y un endpoint para que los clientes programen campañas de marketing SMS con sus mensajes.

Arquitectura: hexagonal (Ports & Adapters) + DDD, implementada en TypeScript + Express, ejecutada como una única función AWS Lambda detrás de API Gateway HTTP API (vía serverless-http). Ver docs/ARCHITECTURE.md para el detalle de las decisiones de diseño.

Reportes

Reporte de mensajes activos programados por estado de envío

Reporte de mensajes activos programados, clasificados por estado de envío

Cuenta los mensajes ACTIVOS (mensaje.estado = 1) cuyo fechaHoraEnvio cae dentro del mes indicado, agrupados por estadoEnvio (Pendiente/Enviado/Error). Filtro por mes obligatorio; filtro por cliente opcional (solo cuenta mensajes de campañas pertenecientes a usuarios de ese cliente). El resumen siempre incluye los 3 estados, con cantidad: 0 cuando no hay mensajes en ese estado.

query Parameters
mes
required
string^\d{4}-(0[1-9]|1[0-2])$
Example: mes=2026-11

Mes a reportar, formato YYYY-MM.

idCliente
integer >= 1
Example: idCliente=1

Filtra el reporte a los mensajes de campañas de este cliente.

Campañas

Programación de campañas de marketing SMS

Programar una campaña de marketing SMS

Crea una campaña y sus mensajes asociados de forma atómica (todo o nada). Todos los mensajes creados nacen con estadoEnvio=1 (Pendiente) y estado=1 (activo). El idUsuario debe existir y estar activo.

Request Body schema: application/json
required
idUsuario
required
integer >= 1
nombre
required
string [ 1 .. 200 ] characters
fechaHoraProgramacion
required
string <date-time>
required
Array of objects (ScheduleCampaignMensajeRequest) non-empty
